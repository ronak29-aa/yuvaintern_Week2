# Week 2 – Advanced Data Visualization and Storytelling with Python

Dataset: Iris Dataset (public benchmark; UCI Machine Learning Repository)
Source: https://archive.ics.uci.edu/dataset/53/iris

## Narrative
The story moves from broad distributions to focused feature evidence, then to relationships, multivariate profiles, and PCA. The central question is: **Which measurements make species differences easiest to see?**

pip install -r requirements.txt
python src/run_pipeline.py
